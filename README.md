# KartenSchmiede AI

Ein statischer Grußkarten-Generator, der Gemini nutzen kann, um Texte und Stilvorschläge zu erzeugen. Öffne `index.html` im Browser oder starte einen kleinen Dev-Server:

```bash
npm run start
```

## Funktionen
- Kartenformat wählen (Quadrat, Hochformat, Querformat, Panorama)
- Anlass & Stil auswählen und Hintergründe würfeln
- Texte live anpassen (Überschrift, Nachricht, Unterschrift)
- Gemini-Integration: Key eingeben, Prompt optional ergänzen und Inhalte generieren
- Druckansicht über den Druck-Button
